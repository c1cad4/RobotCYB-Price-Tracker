# RobotCYB-Price-Tracker в экосистеме cybOS

Браузерное расширение для общей цены токена и виджета.

[Общая карта](https://github.com/c1cad4/cybOS) · [Тестовый стенд](https://github.com/c1cad4/CybOS-demo) · [Каталог компонентов](https://github.com/c1cad4/cybOS/blob/main/ecosystem.json)

## Ответственность

Категория: `markets`. Тип компонента: `extension`.

## Проверка

Из корня репозитория:

```bash
npm test
```

## Границы проверки

Полная загрузка расширения требует браузера, разрешающего unpacked extensions.
