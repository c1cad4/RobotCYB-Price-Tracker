# RobotCYB Price Tracker

Расширение для браузеров Chrome и Edge для отслеживания цен токена RobotCYB в реальном времени с неоновым кибер-зеленым дизайном.

## 🚀 Особенности

- **Отслеживание цен в реальном времени** - автоматическое обновление цен каждые 30 секунд
- **Неоновый кибер-дизайн** - стильный интерфейс с анимациями и эффектами
- **Встроенный график** - интеграция с GMGN API для отображения графиков
- **Виджет на страницах** - перетаскиваемый виджет с ценой на любых веб-страницах
- **Уведомления** - badge с текущей ценой на иконке расширения
- **Горячие клавиши** - Ctrl+Shift+R для показа/скрытия виджета

## 📦 Установка

### Chrome
1. Откройте Chrome и перейдите в `chrome://extensions/`
2. Включите "Режим разработчика" (Developer mode)
3. Нажмите "Загрузить распакованное расширение" (Load unpacked)
4. Выберите папку с расширением

### Edge
1. Откройте Edge и перейдите в `edge://extensions/`
2. Включите "Режим разработчика" (Developer mode)
3. Нажмите "Загрузить распакованное расширение" (Load unpacked)
4. Выберите папку с расширением

## 🎯 Использование

### Popup
- Нажмите на иконку расширения в панели инструментов
- Увидите текущую цену RobotCYB и график
- Используйте кнопки "Обновить" и "Настройки"

### Виджет на страницах
- Виджет автоматически появляется на всех веб-страницах
- Перетаскивайте виджет мышью
- Закрывайте виджет кнопкой "×"
- Используйте Ctrl+Shift+R для показа/скрытия

### График
- Встроенный график от GMGN API
- Автоматическое обновление каждые 15 минут
- Темная тема для лучшей видимости
